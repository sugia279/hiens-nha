## Production order and rollback

After native CI and staging pass, obtain owner approval for production SQL, Auth settings and merge. Record counts/control fingerprints and a current backup using the existing release runbook. Apply only missing additive SQL, deploy the existing Edge Function, configure anonymous/provider settings, then merge/release through existing Pages. Do not submit production test interactions or change roles, ownership assignments, epochs, content/media or Requests controls. Check read-only health/settings/build delivery separately.

Rollback frontend via revert PR; retain guest comments, reaction rows, new display/profile tables, cursors and sanitized-session compatibility. Previous UI remains compatible with the unchanged comment/reaction signatures. Revert the Edge `/me` addition independently if needed. Disable anonymous signup to stop creating new guests only with owner authorization; existing guest sessions remain constrained by DB scope checks. For a full guest-write stop, add a reviewed guard denying `private.is_guest()` in the social wrappers; preserve permanent-user writes and all stored data. Turning off signup alone does not revoke issued guest JWTs. Never drop tables, delete authored Auth users or restore the pre-guest domain functions/grants as an emergency shortcut.
